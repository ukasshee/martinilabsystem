# Martini LabSystem

Minimalistyczna strona-wizytówka Martini LabSystem z wersjami językowymi PL, EN i DE, jasnym oraz grafitowym motywem, polityką prywatności i panelem cookies.

## Uruchomienie lokalne

Wymagany jest Node.js 22 lub nowszy.

```bash
npm install
npm run dev
```

Strona będzie dostępna pod adresem `http://localhost:3000`.

## Weryfikacja

```bash
npm run build
```

## Publikacja na Vercel

1. Zaimportuj repozytorium w panelu Vercel.
2. Wybierz preset `Next.js`.
3. Pozostaw domyślne polecenie budowania i katalog wyjściowy.
4. Kliknij `Deploy`.

Każdy kolejny push do gałęzi produkcyjnej automatycznie uruchomi nowe wdrożenie.
